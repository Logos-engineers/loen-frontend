3 백엔드 서버 실행

DEV 로그인이 백엔드의 /api/v1/dev/token 엔드포인트를 호출하므로, 서버가 실행 중이어야 로그인이 됩니다.

# 1. PostgreSQL 컨테이너 시작
cd loen-backend
docker-compose up -d

# 2. Spring Boot 서버 시작 (http://localhost:8080)
./gradlew bootRun
ℹ️
백엔드 loen-backend/.env 파일도 별도로 세팅되어 있어야 합니다. 팀 채널에서 백엔드 .env 값을 받아 설정하세요.

4 로컬 개발 로그인 방법

Expo Go (에뮬레이터 / 실기기) — DEV 로그인 사용

Google OAuth는 exp:// 스킴을 리다이렉트 URI로 허용하지 않아 Expo Go 환경에서 Google 로그인이 불가능합니다. 로그인 화면 하단의 "개발자 로그인 (DEV)" 버튼을 사용하세요.

앱 실행
→
로그인 화면
→
"개발자 로그인 (DEV)" 버튼 클릭
→
홈 화면 이동
✅
DEV 버튼은 __DEV__ 모드에서만 표시됩니다. 프로덕션 빌드에는 노출되지 않습니다.

Google 로그인 실제 테스트 — EAS 개발 빌드 필요

Google 로그인을 테스트하려면 Expo Go 대신 EAS development build를 사용해야 합니다.

# EAS CLI 설치 (최초 1회)
npm install -g eas-cli

# Android 개발 빌드
npx eas build --platform android --profile development

# iOS 개발 빌드
npx eas build --platform ios --profile development
🚫
Expo Go에서 "Something went wrong trying to finish signing in" 오류가 뜨는 것은 정상입니다. Expo Go 자체의 한계이며 코드 버그가 아닙니다.

5 안드로이드 에뮬레이터 주의사항

안드로이드 에뮬레이터에서 localhost는 에뮬레이터 자기 자신을 가리킵니다. 호스트 머신(개발 PC)의 서버에 접근하려면 10.0.2.2를 사용해야 합니다.

utils/apiClient.ts가 Android 플랫폼을 감지해 자동으로 10.0.2.2:8080으로 연결하도록 이미 설정되어 있으므로 별도 작업은 불필요합니다.

// utils/apiClient.ts — Android 에뮬레이터 자동 처리
if (Platform.OS === 'android') {
  return 'http://10.0.2.2:8080/api/v1';
}
ℹ️
실기기(Wi-Fi)에서 테스트할 경우에는 EXPO_PUBLIC_API_URL=http://<PC의 로컬IP>:8080/api/v1을 .env에 추가하세요.

6 인증 관련 주요 파일

파일역할
store/auth-store.ts Zustand 인증 상태 관리. 토큰 in-memory 보관, SecureStore로 영속화. initialize() · setTokens() · clearTokens() 액션 포함.
utils/apiClient.ts 모든 API 호출 통합 처리. Authorization 헤더 자동 주입, 401 응답 시 Silent Refresh 후 1회 재시도.
app/login.tsx 로그인 화면. Google OAuth (Code + PKCE) + DEV 로그인 버튼.
app/profile-setup.tsx 신규 유저 프로필 설정 화면. 현재 placeholder, 실제 구현 예정.
app/_layout.tsx 인증 상태 기반 라우팅 가드. 비로그인 → /login, 신규 유저 → /profile-setup, 정상 → /(tabs).

7 Silent Refresh 동작 방식

API 호출 시 401 응답이 오면 apiClient.ts가 자동으로 토큰을 갱신하고 원본 요청을 재시도합니다. 컴포넌트 레벨에서는 별도 처리 없이 apiClient()만 호출하면 됩니다.

API 호출
→
401 응답
→
POST /auth/refresh
→
성공 시 토큰 갱신
→
원본 요청 재시도
⚠️
Refresh도 실패하면 clearTokens()를 호출해 강제 로그아웃 처리됩니다. throw된 에러를 컴포넌트에서 잡을 경우 "세션이 만료되었습니다" 메시지를 표시하세요.
