🍓 팀 공용 서버 인프라 구축 계획

라즈베리파이 + SSD + Tailscale 기반 협업 환경 최적화

1. 하드웨어 전략: USB 3.0 SSD 활용

기존 SD 카드의 물리적 한계를 극복하기 위해 USB 3.0 SSD(UDB)를 메인 저장소로 사용합니다.

데이터 안정성

DB의 빈번한 쓰기 작업으로부터 저장 장치 마모 및 데이터 손실 방지.

성능 극대화

SD 카드 대비 압도적인 I/O 속도로 API 응답 및 쿼리 처리 속도 향상.

2. 핵심 인프라 구성 요소

  • Database: PostgreSQL 16 (on Raspberry Pi) - 팀 통합 데이터 저장소.
  • Network: Tailscale VPN - 별도 포트포워딩 없이 100.x.x.x IP로 안전하게 원격 접속.
  • API Engine: Spring Boot (Java 21) - 실시간 팀 공용 API 제공.
  • Documentation: Swagger UI - /swagger-ui/index.html을 통한 API 명세 상시 공유.

3. API Key 및 비밀값 관리 전략

보안과 협업 효율의 균형을 위해 관리 채널을 이원화합니다.

Notion (협업/공유)

팀원 개발용 .env 가이드라인 보관. 접근 권한 관리 및 2FA 설정을 통해 보안 유지.

Server-Side .env

실제 서버 구동에 필요한 핵심 Secret은 라즈베리파이 내부에만 보관하여 외부 유출 원천 차단.

⚠️ 보안 주의사항: 노션 페이지는 절대 '웹에 게시'하지 않으며, 팀원 계정은 반드시 2단계 인증(2FA)을 활성화합니다.

4. 향후 구현 로드맵 (Next Steps)

  1. [Phase 1] DB 환경 세팅: 라즈베리파이 OS SSD 마이그레이션 및 PostgreSQL 설치/권한 설정.
  2. [Phase 2] VPN 연결: 팀원들을 Tailscale Tailnet에 합류시키고 접속 테스트 수행.
  3. [Phase 3] API 배포 및 문서화: Spring Boot 서버 구동 및 Swagger UI 접근 확인.
  4. [Phase 4] 백업 자동화: Cloudflare R2를 활용한 일일 DB 백업 자동 스크립트 등록.
