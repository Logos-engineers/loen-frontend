Java 21 설치

라즈베리파이에서 실행
☕

Eclipse Temurin 21 (JDK)

# 패키지 업데이트
sudo apt update && sudo apt upgrade -y

# Adoptium 저장소 추가
wget -qO - https://packages.adoptium.net/artifactory/api/gpg/key/public \
  | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/adoptium.gpg

echo "deb https://packages.adoptium.net/artifactory/deb \
  $(awk -F= '/^VERSION_CODENAME/{print$2}' /etc/os-release) main" \
  | sudo tee /etc/apt/sources.list.d/adoptium.list

sudo apt update && sudo apt install -y temurin-21-jdk

# 버전 확인
java -version
💡 라즈베리파이 4/5는 64비트 ARM(aarch64)입니다. Temurin은 ARM64를 공식 지원합니다.

PostgreSQL 설치 및 DB 생성

라즈베리파이에서 실행
🐘

설치 & 서비스 시작

sudo apt install -y postgresql postgresql-contrib

# 부팅 시 자동 시작
sudo systemctl enable postgresql
sudo systemctl start postgresql
🗄️

DB 및 유저 생성

sudo -u postgres psql
-- psql 내부
CREATE DATABASE loen_db;
CREATE USER loen_user WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE loen_db TO loen_user;
\q

백엔드 앱 배포

내 노트북 → 라즈베리파이
🏗️

① 내 노트북에서 빌드 후 Pi로 전송

# 내 노트북 (macOS) 에서
cd loen-backend
./gradlew build -x test

# Pi로 전송
scp build/libs/loen-*.jar pi@<PI_IP>:~/loen/
💡 Pi의 IP 주소는 Pi에서 hostname -I로 확인하세요.
⚙️

② Pi에서 .env 파일 생성 및 실행

# Pi에서
mkdir -p ~/loen && cd ~/loen

nano .env
# .env 내용
DB_URL=jdbc:postgresql://localhost:5432/loen_db
DB_USERNAME=loen_user
DB_PASSWORD=your_password
JWT_SECRET=your_jwt_secret_min_32chars
GOOGLE_CLIENT_ID=your_google_client_id
R2_ACCESS_KEY_ID=...
R2_SECRET_ACCESS_KEY=...
R2_ACCOUNT_ID=...
R2_BUCKET_NAME=...
R2_PUBLIC_URL=...
AI_SERVICE_URL=http://localhost:8000
# 실행
java -jar loen-*.jar
🔄

③ systemd 서비스 등록 (재부팅 후 자동 시작)

sudo nano /etc/systemd/system/loen-backend.service
[Unit]
Description=Loen Backend
After=postgresql.service

[Service]
User=pi
WorkingDirectory=/home/pi/loen
EnvironmentFile=/home/pi/loen/.env
ExecStart=/usr/bin/java -jar /home/pi/loen/loen-backend.jar
Restart=on-failure

[Install]
WantedBy=multi-user.target
sudo systemctl daemon-reload
sudo systemctl enable loen-backend
sudo systemctl start loen-backend

# 로그 확인
sudo journalctl -u loen-backend -f

팀원이 접근하는 방법 선택

상황에 따라 선택
📡

같은 Wi-Fi (로컬 IP)

같은 사무실 / 집

공유기에서 Pi의 MAC으로 고정 IP를 할당한 뒤, 팀원이 그 IP로 접속합니다.

# Pi IP 확인
hostname -I

# 팀원 .env
API_URL=http://192.168.x.x:8080
🌐

Cloudflare Tunnel

원격 / 다른 네트워크

무료 HTTPS 공개 URL을 발급해줍니다. 팀원이 어디서든 접속 가능합니다.

# Pi에서 설치
wget https://github.com/cloudflare/cloudflared\
/releases/latest/download/\
cloudflared-linux-arm64.deb
sudo dpkg -i cloudflared-linux-arm64.deb

# 임시 터널 시작
cloudflared tunnel --url http://localhost:8080
🔒

Tailscale (VPN)

원격 / 가장 안전

팀원 모두 Tailscale을 설치해 같은 계정으로 연결하면 사설망처럼 사용합니다.

# Pi에서
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up

# 팀원도 Tailscale 설치 후
# 동일 계정 로그인하면 Pi IP로 접속
⚠️ Cloudflare Tunnel 임시 URL은 cloudflared 재시작마다 바뀝니다. 고정 도메인이 필요하면 Named Tunnel을 만들어야 합니다.
