1 공통 — 출시 빌드 준비

이미 EAS가 구성돼 있어 거의 완료 상태입니다. 확인·보완할 항목:

  • eas.json의 submit.production이 비어 있음 → 스토어 자동 제출을 쓰려면 채워야 함 (Apple appleId/ascAppId/appleTeamId, Google serviceAccountKeyPath). 안 채우면 빌드만 EAS로 하고 업로드는 수동으로도 가능.
  • Android 키스토어: 레포에 @namhyunseo__Loen-project.jks(+_OLD_1)가 있음. EAS 빌드는 보통 EAS가 키 관리(eas credentials). 둘 중 실제 서명키가 무엇인지 확정할 것. 키 분실·교체 시 Play 업로드가 영구 거부됩니다.
  • 버전: eas.json에 autoIncrement: true 설정돼 빌드넘버 자동 증가. OK.
  • ITSAppUsesNonExemptEncryption: false 이미 설정 → 암호화 수출 신고 면제. OK.

2 iOS — App Store Connect

  1. App Store Connect → 앱 → + : 번들 ID com.loen.app 선택, 앱 이름 "Loen" 등록
  2. 빌드 업로드: 
    cd loen-frontend
eas build --platform ios --profile production
eas submit --platform ios --latest   # 또는 Transporter로 수동 업로드
  3. App Store Connect 입력:
    • 스크린샷 (6.7" / 6.5" 필수 · iPad 지원 켜놨으니 iPad용도)
    • 설명, 키워드, 지원 URL
    • 개인정보처리방침 URL = https://legal-eight-eta.vercel.app/privacy.html
    • App Privacy(데이터 수집 항목) 설문 — 구글 로그인/이메일 수집하므로 정직하게 체크
    • 연령 등급
  4. TestFlight 내부 테스트 → "심사 제출"
Sign in with Apple 필수 가능성: 소셜 로그인(구글)을 쓰는 앱은 Apple 로그인도 제공해야 심사 통과(가이드라인 4.8). 현재 구글 로그인만 있으면 거의 확실히 리젝됩니다 — 미리 확인·대응 필요.

3 Android — Play Console

  1. Play Console → 앱 만들기 : 패키지 com.loen.app
  2. 빌드(AAB): 
    eas build --platform android --profile production   # aab 생성
eas submit --platform android --latest
  3. 입력:
    • 스토어 등록정보: 아이콘, 그래픽 이미지, 스크린샷, 설명
    • 개인정보처리방침 URL = .../privacy.html
    • 데이터 안전(Data Safety) 설문
    • 계정 삭제 URL = https://legal-eight-eta.vercel.app/account-deletion.html (준비됨 ✓)
    • 콘텐츠 등급 설문, 타겟 고객층, 광고 포함 여부
  4. 비공개 테스트(20명·14일) 통과 → 프로덕션 트랙 승급 → 심사 제출

4 출시 전 체크리스트

  • settings.tsx의 PRIVACY_POLICY_URL/TERMS_URL이 배포 URL로 들어가 있는지
  • Apple 로그인 추가 여부 결정 (4.8 리젝 방지 — 가장 큰 리스크)
  • Android 서명키 어느 .jks가 진짜인지 확정 + .jks git 커밋 상태 → .gitignore 처리 권장(키 유출 위험)
  • 프로덕션 API(loen-backend-production.up.railway.app)가 심사 기간 내내 떠 있는지 (심사원이 실제 로그인 테스트)
  • 심사용 데모 계정 준비 (구글 로그인이면 테스트 계정 정보 제공)

! 지금 먼저 확정할 2가지

  1. Apple 로그인 필요 여부 — 막판 리젝 1순위
  2. Android 서명키 정리 — 분실 시 복구 불가

둘 다 막판에 발목 잡히는 항목입니다. 그다음 eas.json submit 자동제출 설정을 채우면 됩니다.
