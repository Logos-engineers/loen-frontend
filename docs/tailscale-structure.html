각 집의 공유기가 사설 IP를 부여하므로, 외부에서 192.168.x.x로 직접 접근 불가능

Tailscale이 하는 일

Tailscale을 설치하면 각 기기에 100.x.x.x 형태의 가상 IP를 부여합니다. 이 IP는 물리적 위치와 무관하게 항상 동일하며, 같은 Tailscale 네트워크(tailnet) 안에서는 이 IP로 서로 직접 통신할 수 있습니다.

1

각 기기에 Tailscale 설치 → 코디네이션 서버에 등록 → 100.x.x.x IP 부여

2

초대를 수락한 팀원이 같은 tailnet(가상 네트워크)에 합류

3

기기들이 암호화된 P2P 터널로 직접 연결 → 마치 같은 LAN처럼 통신 가능
