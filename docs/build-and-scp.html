📂

src/main/java/**/*.java

컴파일

사람이 읽는 Java 코드 → 컴퓨터가 실행할 수 있는 바이트코드(.class) 로 변환합니다.

.java → .class
📦

JAR 파일로 패키징

컴파일된 .class 파일들 + 의존 라이브러리(Spring Boot, PostgreSQL 드라이버 등)를 JAR 파일 하나로 압축합니다.

JAR은 사실상 zip 파일입니다. 안에 모든 게 들어있어서 이 파일 하나만 있으면 어디서든 실행 가능합니다.

실행 가능한 단일 파일
✅

결과물 생성

-x test 는 테스트를 건너뛴다는 뜻 → 더 빠르게 빌드 완료

loen-backend/
build/
libs/
loen-ver2-0.0.1-SNAPSHOT.jar ← 이게 결과물
💡 비유하면, 요리 레시피(소스코드)를 실제 완성된 도시락(JAR)으로 만드는 과정입니다. 도시락 하나만 있으면 어디서든 바로 먹을 수 있듯이, JAR 하나만 있으면 서버 어디서든 java -jar 로 실행할 수 있습니다.

scp — 명령어 (Secure Copy)
build/libs/loen-*.jar — 보낼 파일 (내 노트북 경로)
pi — 라즈베리파이의 로그인 유저 이름
192.168.x.x:~/loen/ — 받을 위치 (Pi의 IP + 경로)

🔐 SCP가 SSH를 쓴다는 게 무슨 뜻?

🔑 SSH는 두 컴퓨터 사이에 암호화된 통신 채널을 만드는 프로토콜입니다. 터미널로 원격 서버에 접속할 때 쓰는 바로 그것입니다.
📦 SCP는 그 SSH 채널을 그대로 이용해서 파일을 복사합니다. 즉, 파일이 암호화된 채로 전송되어 중간에 누가 가로채도 내용을 볼 수 없습니다.
🛡️ SSH 비밀번호(또는 SSH 키)로 인증하기 때문에, Pi의 pi 계정 비밀번호를 알아야 전송할 수 있습니다.
💡 비유하면, 일반 USB로 파일을 복사하는 것과 같은 개념인데 — 물리적으로 연결하는 대신 네트워크를 통해 원격으로 복사하는 겁니다. 그리고 전송 중 내용이 암호화되어 있다는 점이 다릅니다.

3 전체 흐름 한눈에

./gradlew build -x test
→
소스코드를 실행 가능한 loen-*.jar 파일로 변환
scp loen-*.jar pi@PI_IP:~/loen/
→
그 파일을 SSH 암호화 채널로 Pi에 복사
java -jar loen-*.jar
→
Pi에서 서버 실행 → :8080 에서 API 서빙 시작
